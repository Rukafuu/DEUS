# Changelog

## 0.3.0

- Added document formatting through `deus fmt` using an isolated temporary file.
- Added open/save diagnostics and a manual check command powered by `deus check`.
- Added configurable CLI executable path and diagnostics toggle.
- Added snippets for common DEUS constructs and retrieval flows.

## 0.2.0

- Added highlighting and indentation behavior for modern `flow name:` source.
- Kept legacy flat syntax highlighting during migration.

## 0.1.0

- Initial installable DEUS language package.
- Syntax highlighting, file association, brackets, comments, and official logo.
