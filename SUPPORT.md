# Support

DEUS is an open source project. GitHub Issues is the official public channel
for support, bug reports, feature requests, usage questions, and language
proposals.

Use the appropriate category:

- **Bug:** a reproducible behavior that does not match the documented design;
- **Feature request:** a proposed capability, including the problem it solves;
- **Security vulnerability:** a possible compromise of the compiler, VM, or host boundary;
- **Usage question:** help understanding installation, syntax, tooling, or examples;
- **Language proposal:** a change to grammar, semantics, bytecode, ABI, or language scope.

Security vulnerabilities must not be reported in a public issue. Follow
[SECURITY.md](SECURITY.md) instead.

Release planning and release announcements are tracked through GitHub Issues.
Project updates are available through [GitHub](https://github.com/rukafuu) and
[LinkedIn](https://linkedin.com/in/rukafuu).
