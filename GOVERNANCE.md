# Governance

DEUS is an open source project using maintainer-led governance while the
project is young. The current maintainer is
[reskyume](https://github.com/reskyume).

Maintainers have final responsibility for architecture, releases, and the
compatibility and security direction of the project. Larger changes should be
discussed through an RFC when they affect language scope, semantics, bytecode,
ABI, VM behavior, or host capabilities.

Decisions prioritize coherence of the language, bounded execution, security,
maintainability, and compatibility. There is no obligation to accept every
contribution. Governance may evolve as the contributor community grows.

No foundation, steering committee, or formal voting body is established by
this document. Governance may evolve as the project and its contributor
community grow.
